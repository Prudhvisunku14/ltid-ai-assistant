# Scenario 01 — Website Requirements

Fictional client: Northstar Studio | Release: 1.0

# Project outcome

Upgrade the starter website into a responsive marketing homepage for a creative technology company.

The website must work locally without a paid hosting account or external commercial API.

# Functional requirements

Navigation — Add a mobile-friendly navigation mechanism that can be operated via keyboard.

Portfolio — Render at least 3 project cards from a structured JavaScript data array or JSON file.

Contact — Create a contact form with name, email and message fields; validate required fields and show success/error status. Local demo submission is acceptable; do not claim the form sends email unless configured.

Sections — Preserve coherent Services, Work and Contact sections and a clear call to action.

Accessibility — Use semantic HTML, alt text where needed, visible focus styles and accessible status messages.

Responsive — Layouts should remain readable on mobile widths (approximately 375px) and desktop widths.

# Acceptance evidence

Show a desktop and mobile screen, explain chosen frontend tools, and run at least 2 automated tests or repeatable checks.

No unauthorised use of a reference brand image or copyrighted source content.
